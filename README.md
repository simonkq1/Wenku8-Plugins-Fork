# 轻小说文库+

> 此腳本源自 [Greasy Fork 上的「轻小说文库+」](https://greasyfork.org/zh-TW/scripts/539514-%E8%BD%BB%E5%B0%8F%E8%AF%B4%E6%96%87%E5%BA%93)。由於原腳本暫時停止更新，且多項功能已損壞，因此建立此維護分支。

## 主要功能

- **閱讀與下載**：解除線上閱讀與下載限制，並增強閱讀介面。
- **書評增強**：支援免重新整理換頁、樓層引用、回覆與編輯，並提供自動刷新、下載及收藏功能。
- **BBCode 編輯器**：修復並增強網站的 BBCode 編輯體驗。
- **書籍與書架**：增強書籍資訊與標籤功能，整合多個書架並允許自訂名稱。
- **收藏與推薦**：提供稍後再讀、每日自動推薦書籍及書評更新檢查。
- **外觀與內容管理**：支援深色模式、自訂背景、首頁區塊摺疊，以及使用者與書籍屏蔽。
- **使用者與帳號**：提供使用者備註、使用者書評查看及帳號快速切換。

*以上為主要功能摘要，腳本另包含其他細部改善與輔助功能。*
